# 电路交换（Circuit Switching）

这是最古老的交换方式，最初用于电话网络。
- **原理**：在传输数据之前，必须先在发送方和接收方之间建立一条**专用的物理通路**。在整个通信期间，这条通路被这对用户独占，即使不传输数据，别人也无法使用。
- **三个阶段**：建立连接（拨号） $\rightarrow$ 数据传输 $\rightarrow$ 释放连接（挂机）。
- **优点**：
    - **时延小**：一旦连接建立，数据透明传输，几乎没有延迟。
    - **实时性强**：适用于语音通话等对连续性要求高的业务。
- **缺点**：
    - **利用率低**：线路被独占，如果用户不说话，带宽就白白浪费。
    - **建立连接时间长**：需要先“握手”建立物理通路。

# 报文交换（Message Switching）

报文交换不需要预先建立连接，它是“存储-转发”模式的雏形。
- **原理**：发送方将一整块信息（称为“报文”，Message）发送给相邻节点。节点先将整个报文**完整接收并存储**，检查无误后，再查找转发表转发给下一个节点。
- **优点**：
    - **无需建立连接**：随时可以发送数据。
    - **线路利用率高**：多条报文可以共享链路，按需分配。
- **缺点**：
    - **延迟大**：每个节点都要经历“接收$\rightarrow$存储$\rightarrow$转发”的过程，报文越长延迟越高。
    - **对设备要求高**：节点（交换机/路由器）必须有足够大的缓冲区来存放整个大报文。

# 分组交换 (Packet Switching)

这是现代互联网（TCP/IP）采用的核心交换技术，是对报文交换的优化。
- **原理**：将大的报文切分成若干个较小的、等长的**分组**（Packet）。每个分组打上包含源地址和目的地址的“首部”（Header），独立地在网络中传输。
- **优点**：
    - **高效**：分组小，节点存储压力小；且可以实现多分组的**并行转发**（管道效应）。
    - **灵活**：每个分组可以走不同的路径到达目的地。
    - **可靠**：如果某个分组丢失，只需重传该分组，不需要重传整个大报文。
- **缺点**：
    - **存在排队延迟**：网络拥塞时，分组在路由器中需要排队。
    - **额外开销**：每个小分组都要带首部，增加了数据量。

# 存储转发（Store-and-Forward）

- **核心思想是**：数据在传输路径上的每一个中间节点（如路由器或交换机）都必须**先完整接收并保存**，经过处理后再**转发**给下一个节点。
- 在一个存储转发的网络中，当一个数据包（或报文）从源主机发出到达一个路由器时，会经历以下三个步骤：
	1. **存储（Store）**：路由器将接收到的比特流缓存到内存中，直到接收完整个数据块（分组或报文）。
	2. **校验与处理**：
	    - **查错**：路由器会计算循环冗余校验（CRC），检查数据在传输过程中是否受损。如果发现错误，通常会丢弃该数据包。
	    - **寻址**：提取数据包首部中的目的地址。
	    - **路由查找**：根据路由表决定该数据包应该从哪一个输出端口发出去。
	3. **转发（Forward）**：将处理完毕的数据包重新转换成电信号或光信号，发送给下一跳（Next Hop）。
- **存储转发**就像是邮局寄信：信件到达每一个分拣中心，工作人员必须先拿到**整封信**，看清地址并盖章确认无误后，才会把它装车发往下一个城市，而不是一边写信一边寄信。

# 频分多路复用 (FDM, Frequency Division Multiplexing)

这是最直观的一种方式，类似于广播电台或有线电视。
- **工作原理**：将物理信道的总带宽划分为若干个较窄的子频带（信道），每个子频带分配给一个用户。所有用户在**同一时间**发送数据，但由于频率不同，互不干扰。
- **关键点**：为了防止频率重叠，各子信道之间通常留有一段空隙，称为**隔离带（Guard Band）**。
- **类比**：像是一条多车道的高速公路，轿车走一车道，货车走二车道。大家同时跑，但互不占道。
	


# 时分多路复用 (TDM, Time Division Multiplexing)

这是数字通信中最常用的静态分配技术。
- **工作原理**：将时间划分为等长的**周期性帧**，每一帧再划分为若干个**固定时隙（Time Slot）**。每个用户被分配一个固定的时隙序号（如：每秒钟的第 1、11、21... 毫秒归用户 A）。
- **关键点**：即使用户 A 现在没有数据要发，属于他的时隙也必须空着，不能给别人。

# 码分多路复用 (CDM/CDMA, Code Division Multiplexing)

这是无线通信（如 3G 通信）的黑科技，它既不分频率也不分时间。
- **工作原理**：所有用户在**同一时间、同一频率**发送信号。每个用户被分配一个唯一的、相互**正交**（Orthogonal）的“码序列”（码片）。发送端用这个码对数据加密，接收端用同样的码进行“内积”运算提取数据。
- **关键点**：数学上利用了向量正交的特性，使得不同用户的信号叠加后仍能被完美分离。
- **类比**：像是在一个嘈杂的鸡尾酒会上，大家都在同时说话。但一对人用中文聊，另一对人用瑞典语聊。因为语言（编码）完全不同，即使声音重叠，你也能在嘈杂中听懂同伴的话。
- 在同一通信链路中，多个发送者通过不同的扩频码（码片序列）区分各自的信号，实现多信号在同一时间、同一频率上的共享传输。这是多路复用的一种具体实现方式，通过“用编码区分信号”而非依赖时间或频率划分，解决了频分/时分复用在动态带宽分配和抗干扰能力上的局限。


# 统计多路复用（Statistical Multiplexing）

- **统计多路复用（Statistical Multiplexing）**，也常被称为**异步时分复用（Asynchronous TDM）**。它是分组交换网络中一种极其高效的带宽分配技术。
- 简单来说，它不再像传统方式那样给每个用户预留“固定座位”，而是实行“有空位就能坐”的动态分配原则。
- 这是对 TDM 的进化，也是**分组交换网络**（如以太网、互联网）的基石。
- **工作原理**：它不再预先分配固定的时隙。系统会动态地观察哪个用户有数据要发，就给谁分配带宽。
- **工作逻辑**：
    1. 数据被切分成**分组**（Packet）。
    2. 每个分组贴上“标签”（地址）。
    3. 分组进入缓冲区（Buffer）排队。
    4. 按“先到先得”或优先级依次发送。
