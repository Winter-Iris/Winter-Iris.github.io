# 莫比乌斯函数

## 定义

$$
\mu(n) = 
\begin{cases}
1, & n = 1 \\
0, & \exists p \text{ 素数}, p^2 \mid n \\
(-1)^k, & n = p_1 p_2 \cdots p_k \text{（$p_i$ 互异）}
\end{cases}
$$

## 重要性质

$$
\sum_{d\mid n}\mu(d) = [n = 1] =
\begin{cases}
1, & n = 1, \\
0, & n \neq 1.
\end{cases}
$$
根据狄利克雷卷积，即

$$\mu * 1 = \varepsilon$$

## 线性筛莫比乌斯函数

```cpp
vector<int> pri;
bool isprime[N];
int mu[N];

void pre_mu() {
    fill(isprime,isprime+N,1);
    isprime[0] = isprime[1] = 0;
    mu[1] = 1;
    for(int i=2;i<N;i++) {
        if(isprime[i]) {
            pri.push_back(i);
            mu[i] = -1;
        }
        for(int j=0;j<pri.size() && (ll)i*pri[j] < N;j++) {
            int p = pri[j];
            isprime[i*p] = 0;
            if(i%p == 0) {
                mu[i*p]=0;
                break;
            }
            mu[i*p] = -mu[i];
        }
    }
}
```




# 莫比乌斯反演

$$
f(n) = \sum_{d\mid n} g(d) \quad\Longleftrightarrow\quad g(n) = \sum_{d\mid n} \mu\!\left(\frac{n}{d}\right) f(d)
$$

- 证明(狄利克雷卷积)：

$$
\begin{aligned}
f &= g * 1 \\
f * 1^{-1} &= g * 1 * 1^{-1} \\
f * \mu &= g
\end{aligned}
$$

# 模板 & tricks

## tricks

### 常见结论

1. 

$$\mu *1=\varepsilon$$

即

$$\sum_{d\mid n} \mu(d) =  [n=1]$$

2. 

$$\mu * \text{id} = \varphi$$

即

$$\sum_{d\mid n} \mu(d) \frac{n}{d} = \varphi(n)$$

### 枚举目标值

- 直接枚举可能的$\gcd$的值，再加上条件

#### 例子1

$$\sum_{k=1}^n \gcd(k,n) = \sum_{d=1}^nd \sum_{k=1}^n [\gcd(k,n)=d]$$

#### 例子2

$$
\sum_{d\mid \gcd(i,j)}\mu(d)
= \sum_{d=1}^{\min(n,m)}\sum_{i=1}^n \sum_{j=1}^m\mu(d) [d\mid i] [d\mid j]
$$

### 提取因数换元

- 常用于构造$[n=1]$，或化简式子的时候
#### 例子1

$$\sum_{k=1}^n [\gcd(k,n)=d]$$

此时显然有$d\mid k$ (隐含了$d\le k$)，设$k = dk'$，有$k'\in [1,n/d]$，（为了方便将换元后的$k'$用$k$替代）

$$
\begin{aligned}
\sum_{k=1}^n [\gcd(k,n)=d]
&= \sum_{k'=1}^{n/d} [\gcd(dk',n)=d] \\
&= \sum_{k'=1}^{n/d} [\gcd(k',n/d)=1] \\
&= \sum_{k=1}^{n/d} [\gcd(k,n/d)=1]
\end{aligned}
$$

#### 例子2
$$\sum_{i=1}^n[d\mid i]$$

换元，令$i=di'$，因为只有$d$的倍数时才对答案有贡献

$$\sum_{i=1}^n[d\mid i] = \sum_{i=1}^{n/d} 1 = \left\lfloor\frac{n}{d}\right\rfloor$$

#### 例子3

令$i=di'$

$$
\sum_{d=1}^n g(d)\sum_{i=1}^n f(i)[\gcd(i,n)=d]
= \sum_{d=1}^n g(d)\sum_{i=1}^{n/d} f(id)\Bigl[\gcd\!\Bigl(i,\frac{n}{d}\Bigr)=1\Bigr]
$$


### 交换求和号顺序化简

- 在求和号内部与求和号枚举变量无关的式子可以提出

$$\sum_{i} g(j)f(i) = g(j)\sum_i f(i)$$

- 求和号交换（若求和指标的范围都是有限的**始终可以交换求和顺序**）

$$\sum_{i=1}^n \sum_{j=1}^m f(i,j) =\sum_{j=1}^m\sum_{i=1}^n  f(i,j)  $$

- 化简时，两者经常结合使用整理式子

#### 例子1

$$
\begin{aligned}
\sum_{i=1}^n \sum_{j=1}^m \sum_{d\mid \gcd(i,j)} \mu(d)
&= \sum_{d=1}^{\min(n,m)} \mu(d) \sum_{i=1}^n[d\mid i] \sum_{j=1}^m [d\mid j] \\
&= \sum_{d=1}^{\min(n,m)} \mu(d) \left\lfloor \frac{n}{d} \right\rfloor\left\lfloor \frac{m}{d} \right\rfloor
\end{aligned}
$$

### 合并换元化简


经常在遇到形如

$$
\sum_{d=1}^n \sum_{s=1}^{n/d}, \quad
\sum_{d=1}^n d \sum_{k=1}^{\min(\left\lfloor m/d \right\rfloor,\left\lfloor n/d \right\rfloor)}
$$

或形如

$$[s\mid \frac{n}{d}],\left\lfloor \frac{n}{ds}\right\rfloor$$

令$t = ds$，这样，将 **两个独立变量的乘积** 作为新求和指标，以达到化简式子的目的。

#### 例子1

$$
\sum_{d=1}^nd\sum_{t}^{\frac{n}{d}} \mu(t)[t\mid \frac{n}{d}] \left\lfloor \frac{n}{dt} \right\rfloor
$$

令$e=dt$，显然根据$d,t$的值域，有$e\in [1,n]$，

且

$$
[t\mid \frac{n}{d}]
$$

在$\gcd(t,d)=1$时等价于$[td\mid n] = [e\mid n]$ ，在$d\mid n,t\mid n$时天然成立，所以有
此时枚举的$d = \gcd(k,n)$，$t=\gcd(k,n/d)$，显然$\gcd(d,t)=1$且$d\mid n,t\mid n$

$$
\begin{aligned}
\sum_{d=1}^nd\sum_{t}^{\frac{n}{d}} \mu(t)[t\mid \frac{n}{d}] \left\lfloor \frac{n}{dt} \right\rfloor
&= \sum_{e=1}^{n} \left\lfloor \frac{n}{e} \right\rfloor \sum_{d\mid e} d\mu\!\left(\frac{e}{d}\right)
\end{aligned}
$$

#### 例子2

$$
\begin{aligned}
&\sum_{d=1}^n d \sum_{k=1}^{\min(\left\lfloor \frac{m}{d} \right\rfloor,\left\lfloor \frac{n}{d} \right\rfloor)} \mu(k)\left\lfloor \frac{n}{dk} \right\rfloor\left\lfloor \frac{m}{dk} \right\rfloor \\
&= \sum_{t=1}^{\min(n,m)} \left\lfloor \frac{n}{t} \right\rfloor\left\lfloor \frac{m}{t} \right\rfloor \sum_{d\mid t} d\mu\!\left(\frac{t}{d}\right)
\end{aligned}
$$

## 一维 gcd 求和
  
$$\sum_{k=1}^n \gcd(k,n) = \sum_{d=1}^nd \sum_{k=1}^n [\gcd(k,n)=d]$$

$$
\begin{aligned}
\sum_{d=1}^nd \sum_{k=1}^n [\gcd(k,n)=d]
&= \sum_{d=1}^nd \sum_{k=1}^{\frac{n}{d}}[\gcd(k,\frac{n}{d}) = 1] \\
&= \sum_{d=1}^nd \sum_{k=1}^{\frac{n}{d}} \sum_{t\mid \gcd(k,\frac{n}{d})} \mu(t) \\
&= \sum_{d=1}^nd \sum_{k=1}^{\frac{n}{d}} \sum_{t}^{\frac{n}{d}} \mu(t)[t\mid k][t\mid \frac{n}{d}] \\
&= \sum_{d=1}^nd\sum_{t}^{\frac{n}{d}} \mu(t)[t\mid \frac{n}{d}] \sum_{k=1}^{\frac{n}{d}} [t\mid k] \\
&= \sum_{d=1}^nd\sum_{t}^{\frac{n}{d}} \mu(t)[t\mid \frac{n}{d}] \left\lfloor \frac{n}{dt} \right\rfloor \\
&= \sum_{d=1}^n d\sum_{t\mid \frac{n}{d}}\mu(t) \left\lfloor \frac{n}{dt} \right\rfloor
\end{aligned}
$$

令$e = dt$

$$
\begin{aligned}
&= \sum_{e=1}^{n} \left\lfloor \frac{n}{e} \right\rfloor \sum_{d\mid e} d\mu\!\left(\frac{e}{d}\right) \\
&= \sum_{e=1}^{n} \left\lfloor \frac{n}{e} \right\rfloor \varphi(e)
\end{aligned}
$$

## 一维gcd数量

$$
\begin{aligned}
\sum_{k=1}^n [\gcd(k,n)=1]
&= \sum_{k=1}^n \sum_{d\mid \gcd(k,n)}\mu(d) \\
&= \sum_{d=1}^n\mu(d) [d\mid n] \sum_{k=1}^n [d\mid k] \\
&= \sum_{d\mid n}\mu(d) \frac{n}{d} \\
&= \varphi(n)
\end{aligned}
$$

- tips:

$$\varphi = \mu * \text{id}$$

## 一维gcd套函数

$$
\begin{aligned}
\sum_{k=1}^n f(\gcd(k,n))
&= \sum_{d=1}^n\sum_{k=1}^n f(d)[\gcd(k,n)=d] \\
&= \sum_{d=1}^n f(d)\sum_{k=1}^{n/d} [\gcd(k,\frac{n}{d})=1] \\
&= \sum_{d=1}^n f(d)\sum_{k=1}^{n/d} \sum_{s\mid\gcd(k,\frac{n}{d})} \mu(s) \\
&= \sum_{d=1}^n f(d)\sum_{s=1}^{n/d}\mu(s)[s\mid \frac{n}{d}]\sum_{k=1}^{n/d} [s\mid k] \\
&= \sum_{d=1}^n f(d)\sum_{s=1}^{n/d}\mu(s)[s\mid \frac{n}{d}]\left\lfloor \frac{n}{ds}\right\rfloor
\end{aligned}
$$

换元，令$t = ds$

$$
\begin{aligned}
\sum_{d=1}^n \sum_{s=1}^{n/d}f(d)\mu(s)[s\mid \frac{n}{d}]\left\lfloor \frac{n}{ds}\right\rfloor
&= \sum_{t\mid n} \frac{n}{t}\sum_{d\mid t} f(d)\mu\!\left(\frac{t}{d}\right) \\
&= \sum_{t\mid n} \frac{n}{t} (f*\mu)(t) \\
&= (\text{id} * f * \mu)(t) \\
&= (f* \varphi)(t)
\end{aligned}
$$

## 一维函数乘gcd套函数

$$
\begin{aligned}
\sum_{i=1}^n f(i)g(\gcd(i,n))
&= \sum_{d=1}^n\sum_{i=1}^n f(i)g(d)[\gcd(i,n)=d] \\
&= \sum_{d=1}^n g(d)\sum_{i=1}^n f(i)[\gcd(i,n)=d] \\
&= \sum_{d=1}^n g(d)\sum_{i=1}^{n/d} f(id)[\gcd(i,\frac{n}{d})=1] \\
&= \sum_{d=1}^n g(d)\sum_{i=1}^{n/d} f(id)\sum_{k\mid\gcd(i,\frac{n}{d})}\mu(k) \\
&= \sum_{d=1}^n g(d)\sum_{k=1}^{n/d}\mu(k) [k\mid \frac{n}{d}]\sum_{i=1}^{n/d} f(id)[k\mid i] \\
&= \sum_{d=1}^n g(d)\sum_{k=1}^{n/d}\mu(k) [k\mid \frac{n}{d}]\sum_{i=1}^{\frac{n}{dk}} f(ikd)
\end{aligned}
$$

令$t=dk$

$$
\begin{aligned}
&= \sum_{t\mid n} \sum_{d\mid t} g(d)\mu\!\left(\frac{t}{d}\right)\sum_{i=1}^{\frac{n}{t}} f(it) \\
&= \sum_{t\mid n} (g*d)(t) \sum_{i=1}^{\frac{n}{t}} f(it)
\end{aligned}
$$

## 二维GCD求和


$$\sum_{i=1}^n \sum_{j=1}^m gcd(i,j)$$

$$
\begin{aligned}
\sum_{i = 1}^n \sum_{j = 1}^m \gcd(i, j)
&= \sum_{d=1}^n d \sum_{i = 1}^n \sum_{j = 1}^m [\gcd(i, j) = d] \\
&= \sum_{d=1}^n d \sum_{i = 1}^n \sum_{j = 1}^m [\gcd(i/d, j/d) = 1] \\
&= \sum_{d=1}^n d\sum_{i = 1}^{\left\lfloor \frac{n}{d} \right\rfloor} \sum_{j = 1}^{\left\lfloor \frac{m}{d} \right\rfloor} [\gcd(i, j) = 1] \\
&= \sum_{d=1}^n d\sum_{i = 1}^{\left\lfloor \frac{n}{d} \right\rfloor} \sum_{j = 1}^{\left\lfloor \frac{m}{d} \right\rfloor}\sum_{k\mid \gcd(i,j)}\mu(k) \\
&= \sum_{d=1}^n d \sum_{k=1}^{\min(\left\lfloor \frac{m}{d} \right\rfloor,\left\lfloor \frac{n}{d} \right\rfloor)} \mu(k)\sum_{k\mid i} 1\sum_{k\mid j}1 \\
&= \sum_{d=1}^n d \sum_{k=1}^{\min(\left\lfloor \frac{m}{d} \right\rfloor,\left\lfloor \frac{n}{d} \right\rfloor)} \mu(k)\sum_{i=1}^{\left\lfloor \frac{n}{d} \right\rfloor} [k\mid i]\sum_{j=1}^{\left\lfloor \frac{m}{d} \right\rfloor}[k\mid j] \\
&= \sum_{d=1}^n d \sum_{k=1}^{\min(\left\lfloor \frac{m}{d} \right\rfloor,\left\lfloor \frac{n}{d} \right\rfloor)} \mu(k)\left\lfloor \frac{n}{dk} \right\rfloor\left\lfloor \frac{m}{dk} \right\rfloor
\end{aligned}
$$

- 令$t=dk$

$$
\begin{aligned}
&\sum_{d=1}^n d \sum_{k=1}^{\min(\left\lfloor \frac{m}{d} \right\rfloor,\left\lfloor \frac{n}{d} \right\rfloor)} \mu(k)\left\lfloor \frac{n}{dk} \right\rfloor\left\lfloor \frac{m}{dk} \right\rfloor \\
&= \sum_{t=1}^{\min(n,m)} \left\lfloor \frac{n}{t} \right\rfloor\left\lfloor \frac{m}{t} \right\rfloor \sum_{d\mid t} d\mu\!\left(\frac{t}{d}\right) \\
&= \sum_{t=1}^{\min(n,m)} \left\lfloor \frac{n}{t} \right\rfloor\left\lfloor \frac{m}{t} \right\rfloor \varphi(t)
\end{aligned}
$$


- 例题：
- [P2398 GCD SUM](https://www.luogu.com.cn/problem/P2398)

#include <bits/stdc++.h>
#define ll long long
#define ld long double
#define ull unsigned long long
//#define int long long
#define IOS ios::sync_with_stdio(false);cin.tie(nullptr);
#define endl '\n' 
#define pii pair<int,int>

const int INF = 0x3f3f3f3f;
const ll INFLL = 0x3f3f3f3f3f3f3f3f;
const double PI = acos(-1.0);

//ifstream fin("input.txt");

const int N = 1e5+5;

int n;
vector<int> pri;

int phi[N];
ll prephi[N];

void pre_euler_phi() {
    fill(isprime,isprime+1+n,1);
    isprime[0] = isprime[1] = 0;
    phi[1] = 1;
    for(int i=2;i<=n;i++) {
        if(isprime[i]) {
            pri.push_back(i);
            phi[i] = i-1;
        }
        for(int j=0;j<pri.size() && (ll)i*pri[j] <= n;j++) {
            int p = pri[j];
            isprime[i*p]=0;
            if(i%p == 0) {
                phi[i*p] = phi[i] * p ;
                break;
            }
            phi[i*p] = phi[i] * phi[p];
        }
    }
}

signed main()
{
    IOS
    cin>>n;
    pre_euler_phi();
    for(int i=1;i<=n;i++) prephi[i] = prephi[i-1] + phi[i];
    ll res=0;
    for(ll l=1,r;l<=n;l=r+1) {
        if(n/l == 0) break;
        r = n/(n/l);
        res += (prephi[r]-prephi[l-1])*(n/l)*(n/l);
    }
    cout<<res<<endl;

    //fin.close(),fout.close();
    return 0;
}

## 二维GCD计数

$$
\begin{aligned}
\sum_{i=1}^n \sum_{j=1}^m [\gcd(i,j)=1]
&= \sum_{i=1}^n \sum_{j=1}^m \sum_{d\mid \gcd(i,j)} \mu(d) \\
&= \sum_{d=1}^{\min(n,m)} \mu(d) \sum_{i=1}^n[d\mid i] \sum_{j=1}^m [d\mid j] \\
&= \sum_{d=1}^{\min(n,m)} \mu(d) \left\lfloor \frac{n}{d} \right\rfloor\left\lfloor \frac{m}{d} \right\rfloor
\end{aligned}
$$

- 例题：
- [P3455 [POI 2007] ZAP-Queries](https://www.luogu.com.cn/problem/P3455)

## 二维GCD套函数

$$
\begin{aligned}
\sum_{i=1}^n \sum_{j=1}^m f(\gcd(i,j))
&= \sum_{d=1}^{\min(n,m)} f(d)\sum_{i=1}^n \sum_{j=1}^m [\gcd(i,j)=d] \\
&= \sum_{d=1}^{\min(n,m)} f(d)\sum_{i=1}^{n/d} \sum_{j=1}^{m/d} [\gcd(i,j)=1] \\
&= \sum_{d=1}^{\min(n,m)} f(d) \sum_{i=1}^{n/d} \sum_{j=1}^{m/d}\sum_{k\mid\gcd(i,j)}\mu(k) \\
&= \sum_{d=1}^{\min(n,m)} f(d) \sum_{k}^{\min(n/d,m/d)}\mu(k) \sum_{i=1}^{n/d} [k\mid i]\sum_{j=1}^{m/d}[k\mid j] \\
&= \sum_{d=1}^{\min(n,m)} f(d) \sum_{k}^{\min(n/d,m/d)}\mu(k)\left\lfloor \frac{n}{dk} \right\rfloor\left\lfloor \frac{m}{dk} \right\rfloor
\end{aligned}
$$

令$t=dk$

$$
\begin{aligned}
&= \sum_{t}^{\min(n,m)} \left\lfloor \frac{n}{t} \right\rfloor\left\lfloor \frac{m}{t} \right\rfloor\sum_{d\mid t} f(d)\mu\!\left(\frac{t}{d}\right) \\
&= \sum_{t}^{\min(n,m)} \left\lfloor \frac{n}{t} \right\rfloor\left\lfloor \frac{m}{t} \right\rfloor (f*\mu)(t)
\end{aligned}
$$

## 二维函数乘函数乘GCD套函数

$$
\begin{aligned}
&\sum_{i=1}^n \sum_{j=1}^m f(i)g(j)h(\gcd(i,j)) \\
&= \sum_{d=1}^{\min(n,m)} h(d)\sum_{i=1}^n \sum_{j=1}^m f(i)g(j)[\gcd(i,j)=d] \\
&= \sum_{d=1}^{\min(n,m)} h(d)\sum_{i=1}^{n/d} \sum_{j=1}^{m/d} f(id)g(jd)[\gcd(i,j)=1] \\
&= \sum_{d=1}^{\min(n,m)} h(d)\sum_{i=1}^{n/d} \sum_{j=1}^{m/d} f(id)g(jd)\sum_{k\mid\gcd(i,j)}\mu(k) \\
&= \sum_{d=1}^{\min(n,m)} h(d)\sum_{k}^{\min(n/d,m/d)}\mu(k) \sum_{i=1}^{n/d} f(id) [k\mid i]\sum_{j=1}^{m/d} g(jd)[k\mid j] \\
&= \sum_{d=1}^{\min(n,m)} h(d)\sum_{k}^{\min(n/d,m/d)}\mu(k) \sum_{i=1}^{\frac{n}{dk}} f(idk) \sum_{j=1}^{\frac{m}{dk}} g(jdk)
\end{aligned}
$$

令$t=dk$

$$
\begin{aligned}
&= \sum_{t=1}^{\min(n,m)} \sum_{i=1}^{\frac{n}{t}} f(it) \sum_{j=1}^{\frac{m}{t}} g(jt) \sum_{d\mid t}h(d)\mu\!\left(\frac{t}{d}\right) \\
&= \sum_{t=1}^{\min(n,m)} \left[\sum_{i=1}^{\frac{n}{t}} f(it) \sum_{j=1}^{\frac{m}{t}} g(jt)\right](h*\mu)(t)
\end{aligned}
$$

## 二维LCM求和

$$
\begin{aligned}
\sum_{i=1}^n \sum_{j=1}^m \operatorname{lcm}(i,j)
&= \sum_{i=1}^n \sum_{j=1}^m \frac{ij}{\gcd(i,j)} \\
&= \sum_{d=1}^{\min(n,m)}\sum_{i=1}^n \sum_{j=1}^m \frac{ij}{d}[\gcd(i,j)=d] \\
&= \sum_{d=1}^{\min(n,m)}\sum_{i=1}^{n/d} \sum_{j=1}^{m/d} dij[\gcd(i,j)=1] \\
&= \sum_{d=1}^{\min(n,m)}d\sum_{i=1}^{n/d} \sum_{j=1}^{m/d} ij\sum_{k\mid \gcd(i,j)}\mu(k) \\
&= \sum_{d=1}^{\min(n,m)}d\sum_{k}^{\min(n/d,m/d)}\mu(k)\sum_{i=1}^{n/d} i[k\mid i]\sum_{j=1}^{m/d} j[k\mid j] \\
&= \sum_{d=1}^{\min(n,m)}d\sum_{k}^{\min(n/d,m/d)}\mu(k)\sum_{i=1}^{\frac{n}{dk}} ki\sum_{j=1}^{\frac{m}{dk}} kj
\end{aligned}
$$

令

$$
G(n) = \frac{n(n+1)}{2} = \sum_{i=1}^{n}i
$$

则有

$$
\begin{aligned}
\sum_{d=1}^{\min(n,m)}d\sum_{k}^{\min(n/d,m/d)}\mu(k)\sum_{i=1}^{\frac{n}{dk}} ki\sum_{j=1}^{\frac{m}{dk}} kj
&= \sum_{d=1}^{\min(n,m)}d\sum_{k}^{\min(n/d,m/d)}\mu(k)k^2 G\!\left(\frac{n}{dk}\right)G\!\left(\frac{m}{dk}\right)
\end{aligned}
$$

令$t=dk$

$$
\begin{aligned}
&= \sum_{t=1}^{\min(n,m)} t\,G\!\left(\frac{n}{t}\right)G\!\left(\frac{m}{t}\right)\sum_{k\mid t} k\mu(k)
\end{aligned}
$$

令

$$
f(t) = \sum_{k\mid t} k\mu(k)
$$
$f(t)$为积性函数，可以通过线性筛预处理
- 当$t$为质数
$$f(t) = \mu(1) + t\mu(t) = 1-t$$
- 当$t$为合数，$t=p\times i$，$p$ 为 $t$ 的最小质因数，分两种情况
	- $p\not \mid i$
$$f(t) = f(p)f(i) = (1-p)f(i)$$
	- $p\mid i$，$i=p^km\:\:$，$t=p^{k+1}m$，$(k\ge 1)$，由于对总和有贡献的因数一定是由互不相同的质因数组成的，且t与i的质因数集合相同，故
$$f(t) = f(i)$$
- 例题：
- [P1829 [集训队互测 2010] Crash的数字表格 / JZPTAB]( https://www.luogu.com.cn/problem/P1829)

const int MOD = 20101009;

ll add(ll a, ll b, ll mod) {
    a %= mod; b %= mod;
    ll res = a + b;
    if (res >= mod) res -= mod;
    return res;
}

ll sub(ll a, ll b, ll mod) {
    a %= mod; b %= mod;
    ll res = a - b;
    if (res < 0) res += mod;
    return res;
}

ll mul(ll a, ll b, ll mod) {
    a %= mod; b %= mod;
    ll res = a * b - (ll)((long double)a * b / mod) * mod;
    if (res < 0) res += mod;
    if (res >= mod) res -= mod;
    return res;
}

ll qpow(ll a,ll p,ll mod) {
    ll res=1;
    while(p) {
        if(p&1) res=mul(res,a,mod);
        a=mul(a,a,mod);p>>=1;
    }
    return res;
}

ll inv(ll x,ll mod) {
    return qpow(x,mod-2,mod);
}


void pre() {
    fill(isprime,isprime+1+maxn,1);
    isprime[0]=isprime[1]=0;
    f[1]=1;
    for(int i=2;i<=maxn;i++) {
        if(isprime[i]) {
            pri.push_back(i);
            f[i] = sub(1,i,MOD);
        }
        for(int j=0;j<pri.size() && (ll)i*pri[j] <=maxn;j++) {

}

    return mul(mul(n,n+1,MOD),inv(2,MOD),MOD);
}
