数论分块可以快速计算一些形如
$$\sum_{i=1}^nf(i)g\left(\left\lfloor\dfrac ni\right\rfloor\right)$$

的和式．如果可以在 𝑂(1)![](data:image/gif;base64,R0lGODlhAQABAIAAAAAAAP///yH5BAEAAAAALAAAAAABAAEAAAIBRAA7 "O(1)") 时间内计算出 $\sum_{i=l}^{r}f(i)$ 或已经预处理出 𝑓![](data:image/gif;base64,R0lGODlhAQABAIAAAAAAAP///yH5BAEAAAAALAAAAAABAAEAAAIBRAA7 "f") 的前缀和时，数论分块就可以在 𝑂(√𝑛)![](data:image/gif;base64,R0lGODlhAQABAIAAAAAAAP///yH5BAEAAAAALAAAAAABAAEAAAIBRAA7 "O(\sqrt{n})") 时间内计算出上述和式的值．

# 原理

将 $1\sim n$ 之间的整数按照 $\left\lfloor\dfrac{n}{i}\right\rfloor$ 的取值分为若干块．设

$$D(n) = \left\{\left\lfloor\dfrac{n}{i}\right\rfloor : 1 \le i \le n,~i\in\mathbf N_+\right\}$$
这就是 $\left\lfloor\dfrac{n}{i}\right\rfloor$ 所有可能的取值集合．

这样的不同取值只有 $O(\sqrt{n})$ 个．所以，数论分块得到的块的数目只有 $O(\sqrt{n})$ 个．
并且每一种数值对应的 $i$ 是一个连续的区间。

对于每个块的左右端点(满足$\left\lfloor\dfrac{n}{i}\right\rfloor = d$ 的所有点 的 $i$ 的取值范围)为
$$  \left\lfloor\frac{n}{d+1}\right\rfloor + 1 \le i\le \left\lfloor{\frac{n}{d}}\right\rfloor$$
所以，如果已知块的左端点$l$，右端点为
$$r=\left\lfloor\dfrac n{\lfloor n/l\rfloor}\right\rfloor$$


- 证明：
$$\left\lfloor\dfrac{n}{i}\right\rfloor \le \frac{n}{i} < \left\lfloor\dfrac{n}{i}\right\rfloor+1$$
令$\left\lfloor\dfrac{n}{i}\right\rfloor = d$

$$d \le \frac{n}{i} < d+1$$
$$  \frac{n}{d+1} <i\le \frac{n}{d}$$
$$  \left\lfloor\frac{n}{d+1}\right\rfloor + 1 \le i\le \left\lfloor{\frac{n}{d}}\right\rfloor$$
- 每个块的右端点的集合恰为 $D(n)$

# 过程

为计算和式
$$\sum_{i=1}^nf(i)g\left(\left\lfloor\dfrac ni\right\rfloor\right)$$

的取值，可以依据 $\left\lfloor\dfrac ni\right\rfloor$ 的取值将标号 $i=1,2,\cdots,n$ 分块．因为 $\left\lfloor\dfrac ni\right\rfloor$ 取值相同的标号是一段连续整数 $[l,r]$，所以该块中和式的取值为

$$\left(\sum_{i=l}^rf(i)\right)\cdot g\left(\left\lfloor\dfrac nl\right\rfloor\right)$$

为了快速计算该和式，通常需要能够快速计算左侧关于 $f$ 的和式．有些时候，该和式的表达式是已知的，可以在 $O(1)$ 时间内完成单次计算；有些时候，可以预处理出它的前缀和，仍然可以在 𝑂(1)![](data:image/gif;base64,R0lGODlhAQABAIAAAAAAAP///yH5BAEAAAAALAAAAAABAAEAAAIBRAA7 "O(1)") 时间内完成单次查询．

在顺次计算每块左右端点时，当前块的左端点 𝑙![](data:image/gif;base64,R0lGODlhAQABAIAAAAAAAP///yH5BAEAAAAALAAAAAABAAEAAAIBRAA7 "l") 就等于前一块的右端点再加 1![](data:image/gif;base64,R0lGODlhAQABAIAAAAAAAP///yH5BAEAAAAALAAAAAABAAEAAAIBRAA7 "1")，而当前块的右端点就等于 $\left\lfloor\dfrac n{\lfloor n/l\rfloor}\right\rfloor$

- 例题：

- 𝑇![](data:image/gif;base64,R0lGODlhAQABAIAAAAAAAP///yH5BAEAAAAALAAAAAABAAEAAAIBRAA7 "T") 组数据，每组一个整数 𝑛![](data:image/gif;base64,R0lGODlhAQABAIAAAAAAAP///yH5BAEAAAAALAAAAAABAAEAAAIBRAA7 "n")．对于每组数据，输出$\sum_{i=1}^n\left\lfloor\dfrac ni\right\rfloor$
```cpp
#include <bits/stdc++.h>
#define ll long long

ll h(ll n) {
```

# 模板

- 计算：$\sum_{i=1}^n\left\lfloor\dfrac ni\right\rfloor$
```cpp
ll n;cin>>n;
ll res = 0;
for(ll l=1,r;l<=n;l=r+1) {
	if(n/l == 0) break;
	r=n/(n/l);
	res += (r-l+1)*(n/l);
}
```
