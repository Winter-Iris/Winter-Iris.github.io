# 定义


- 欧拉函数（Euler's totient function），即 $\varphi(n)$，表示的是小于等于 $n$ 和 $n$ 互质的数的个数．
- 比如说 $\varphi(1) = 1$. 当 𝑛![](data:image/gif;base64,R0lGODlhAQABAIAAAAAAAP///yH5BAEAAAAALAAAAAABAAEAAAIBRAA7 "n") 是质数的时候，显然有 $\varphi(n) = n - 1$

# 性质

- 欧拉函数是 **积性函数**。 即对任意满足 $\gcd(a, b) = 1$ 的整数 $(a,b)$ 有 $\varphi(ab) = \varphi(a)\varphi(b)$
- 特别地，当 𝑛![](data:image/gif;base64,R0lGODlhAQABAIAAAAAAAP///yH5BAEAAAAALAAAAAABAAEAAAIBRAA7 "n") 是奇数时 $\varphi(2n) = \varphi(n)$
- 若$n=p^k$，$k$ 为质数，则 $\varphi(n) = p^k-p^{k-1}$
- 设$n = \prod_{i=1}^s p_i^{k_i}$ ，其中 $p_i$ 为质数，则 $\varphi(n) = n \times \prod_{i=1}^s \frac{p_i-1}{p_i}$

$$\varphi(n) = \varphi(\prod_{i=1}^s p_i^{k_i}) = \prod_{i=1}^s \varphi(p_i^{k_i})
=\prod_{i=1}^s p_i^{k_i-1}(p_i-1)= \prod_{i=1}^s p_i^{k_i}(1-\frac{1}{p_i}) = n\prod_{i=1}^s(1-\frac{1}{p_i})
$$

# 实现

## 单个数

```cpp
#include <cmath> 
int euler_phi(int n) 
{ 
	int ans = n; 
	for (int i = 2; i * i <= n; i++) 
	if (n % i == 0) 
	{ 
		ans = ans / i * (i - 1); 
		while (n % i == 0) 
		n /= i;
	} 
	if (n > 1) 
		ans = ans / n * (n - 1); 
	return ans; 
 }
```

## 筛法求欧拉函数

- 注意到在线性筛中，每一个合数都是被最小的质因子筛掉
- 比如设 $p_1$ 是 $n$ 的最小质因子，$n' = \frac{n}{p_1}$，那么线性筛的过程中 $n$ 通过 $n' \times p_1$ 筛掉．

- 若 $n' \equiv 0 \pmod{p_1}$ 
$$\varphi(n) = n \prod_{i=1}^s \frac{p_i-1}{p_i} = p_1\cdot n'\prod_{i=1}^s \frac{p_i-1}{p_i} = p_1 \varphi(n') $$
- 若$n' \not \equiv 0 \pmod{p_1}$ 
$$\varphi(n) = \varphi(n')\varphi(p_1) = (p_1-1)\varphi(n')$$
```cpp
vector<int> pri;
bool isprime[N];        
int phi[N];

void pre_euler_phi(int n) {
    fill(isprime, isprime+1+n,1);
    isprime[1] = isprime[0] = 0;
    phi[1] = 1;
    for(int i=2;i<=n;i++) {
        if(isprime[i]) {
            pri.push_back(i);
            phi[i] = i-1;
        }
        for(int j=0;j<pri.size() && 1ll*i*pri[j] <= n;j++) {
            int p=pri[j];
            isprime[i*p] = 0; 
            if(i % p == 0) {
                phi[i*p] = phi[i] * p;
                break;
            }
            phi[i*p] = phi[i] * phi[p];
        }
    }
}
```
